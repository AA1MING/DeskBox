# DeskBox 1.2.4

- 优化文件夹切换：在切换前准备图标，反复打开时直接复用缓存。
- 鼠标在文件夹上停留时提前加载内部图标；移开后停止继续预加载。
- 去掉逐个图标与整个区域叠加的淡入动画，文件夹切换改为短距离平移，减少闪烁。
- 新增类似 Dock 的悬停反馈：图标在约 200 ms 内放大 16% 并上浮，移开后柔和回弹；文字与布局保持稳定。

验证：121 项回归检查与 15 项单文件打包自检通过，覆盖首次打开、缓存复用、快速导航、真实鼠标悬停和拖拽。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
可在设置中检查更新并选择“更新并重启”，配置与收纳数据保留。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
