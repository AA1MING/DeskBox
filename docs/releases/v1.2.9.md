# DeskBox 1.2.9

本次更新让图标在应用第一次启动时就完全准备好：整个收纳盒（含所有分组）的图标在启动后由后台队列一次性提取并缓存，正常启动无需等待、无需联网。

- 应用一启动就预热整棵收纳树的图标，包含所有嵌套分组与多层子文件夹里的项目。
- 第一次打开面板、第一次进入任意文件夹都直接使用已就绪的图标，不再出现占位图，也不再提示“正在准备文件夹图标…”。
- 文件夹切换时会等待目标分组的图标就绪后再切换，杜绝“先进去再补图”的闪烁；切换不重置缓存，重复进出立即可用。
- 新收纳进来的文件会在保存后立即在后台补全图标。

验证：回归检查新增“预热覆盖整棵项目树”“启动预热为每个嵌套项准备好真实图标”两项断言，覆盖多层嵌套分组。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
可在设置中检查更新并选择“更新并重启”，配置与收纳数据保留。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
