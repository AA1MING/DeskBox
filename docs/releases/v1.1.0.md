# DeskBox 1.1.0

## 外观与启动

- 修复云母、亚克力和纯色切换；主面板、设置窗口和应用内菜单使用一致材质。
- 统一柔和的淡入淡出与轻微位移，增加菜单、控件、滚动和排序动画。
- 后台加载并缓存图标，修复首次显示时的空面板和闪黑。
- 首次使用自动展开面板，之后通过托盘或热键呼出；开机启动只驻留托盘。
- 精简界面说明，取消重复启动气泡。

## 排序与搜索

- 文件夹/分组置顶；英文按 A–Z 在前，中文按完整拼音在后，数字按数值排序。
- 顶部实时搜索覆盖所有分组，支持名称、完整拼音和拼音首字母。
- 清空搜索恢复原分组，支持 Ctrl+F、Enter 和 Esc。

验证：56 项回归检查与 15 项打包后自检全部通过；材质、设置和菜单在当前 Windows 11 上完成截图复核。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
云母和亚克力需要开启 Windows“透明效果”。
升级保留配置与收纳数据。拼音数据许可见随包提供的 THIRD_PARTY_NOTICES.md。
