# DeskBox 1.2.5

- 修复设置页打开时背景先闪一下、内容随后出现的问题，首帧准备好后再显示。
- 统一采用接近 macOS 的轻微缩放与柔和弹性，常规动画约 180–220 ms。
- 图标悬停放大并回弹；按钮悬停轻微放大、按下快速收缩，文字和布局保持稳定。
- 主面板、设置、菜单与输入对话框使用一致的开合节奏，关闭时避免留下空白窗口。
- 滚动反向立即响应；修复快速开关、窗口刚打开就按 Esc 时的动画冲突。

验证：134 项回归检查与 15 项单文件打包自检通过，覆盖首帧可见性、窗口尺寸稳定、连续和反向滚动、按钮反馈、快速取消、图标缓存与原生拖拽。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
可在设置中检查更新并选择“更新并重启”，配置与收纳数据保留。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
