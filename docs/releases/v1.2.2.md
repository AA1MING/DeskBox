# DeskBox 1.2.2

- 删除排序菜单中的“紧凑排列”选项及多余分隔线。
- 修复运行期间重命名 EXE 后“更新并重启”仍查找旧文件名的问题。
- 更新前重新定位正在运行的程序，核对版本和目录写入权限；无法定位时给出明确的恢复提示。

验证：112 项回归检查、17 项更新替换与回滚检查、15 项单文件打包自检通过。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。

旧版若已因运行期间改名而更新失败，请先从托盘退出 DeskBox，再从当前文件位置重新打开后检查更新；也可退出后手动替换为本版。配置与收纳数据保留。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
