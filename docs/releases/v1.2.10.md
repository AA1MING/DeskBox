# DeskBox 1.2.10

本次更新修复开机自启动在部分电脑或部分情况下不生效的问题，并让自启项在程序移动/更新后自动跟随。

- 自启改为“双机制”写入：注册表 `HKCU\...\Run` 与“启动”文件夹快捷方式同时创建，任意一个可用即可生效；两者都固定使用当前用户路径，不依赖程序所在目录、盘符或是否便携运行，换一台电脑也能正常开机启动。
- 启动时自动校正：如果自启项仍指向旧位置（例如程序被移动，或更新后换了盘/目录），会按上次保存的设置自动修复并提示。
- 被用户关闭时，会按设置清理注册表与启动文件夹里的残留项，避免“关不掉”或半开启状态。
- 修复更新后自启指向旧文件的问题：更新换盘/换目录后，下一次启动会自动把自启项指向新的程序路径。

验证：新增自启机制与路径校正的回归断言，覆盖注册表与启动文件夹两种机制。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
可在设置中检查更新并选择“更新并重启”，配置与收纳数据保留。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
