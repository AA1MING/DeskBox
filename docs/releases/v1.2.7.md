# DeskBox 1.2.7

- 面板弹出与收起改用 Fluent 风格的 cubic-bezier 缓动曲线，替代此前机械感较强的固定 CubicEase：进入 220 ms 强力减速落位，收起 160 ms 先缓后快。
- 修复收起动画的硬切感：此前内容只淡到 0.88 就直接隐藏窗口，视觉上像突然消失；现在内容完整淡出到 0，缩放与位移同步收尾后再隐藏。
- 弹出起点缩放由 0.985 调整为 0.98、上移 6 px，展开方向更明确，同时保持克制不夸张。
- 设置页、右键菜单与输入框共用同一套进入/退出曲线，各弹层开关手感一致。

验证：动画契约检查覆盖进入/退出时长区间、缓动曲线形状、EaseIn 模式与端点取值；回归套件其余检查保持通过。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
可在设置中检查更新并选择“更新并重启”，配置与收纳数据保留。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
