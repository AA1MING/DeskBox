# DeskBox 1.2.11

本次更新修复点击面板外部有时不关闭的问题。

- 收起判定改用全局鼠标钩子，不再依赖窗口是否成功拿到前台焦点；此前部分系统或全屏程序下窗口激活会静默失败，导致点击外部没有反应，现在都能稳定收起。
- 精确区分内外：点击面板本身、正在打开的右键菜单或输入框不会关闭；点击任务栏/托盘图标交给托盘逻辑处理，避免重复收起。
- 固定（图钉）状态仍然保持不自动收起。

验证：回归检查新增 9 项断言，覆盖钩子安装/卸载与内/外/固定/菜单/未命中判定。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
可在设置中检查更新并选择“更新并重启”，配置与收纳数据保留。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
