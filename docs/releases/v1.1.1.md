# DeskBox 1.1.1

- 搜索框移到顶部中间，与右侧按钮等高；窄面板自动调整按钮排列。
- 点击搜索框隐藏“搜索”提示，点击框外退出输入，保留已有关键词。
- 快捷方式可拖回桌面或资源管理器，默认移动，按住 Ctrl 则复制。
- 文件收纳和快捷方式解析改为后台处理，减少拖动和排序卡顿；退出时等待收纳与保存完成。

验证：74 项回归检查、7 项搜索焦点交互检查和 15 项打包自检通过。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
升级时退出旧版，再运行新程序；已有配置与收纳数据保留。
附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
