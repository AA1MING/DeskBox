# DeskBox 1.2.17

本次更新修复主面板与设置页主题不统一的问题。

- 根因：主面板是无边框窗口、完全跟随应用主题；而设置页带 Windows 系统标题栏，标题栏颜色与深浅此前只跟随系统主题。当应用主题与系统主题相反（例如系统浅色、应用深色）时，设置页会出现“标题栏一套颜色、界面另一套颜色”，看起来就是主题不统一。
- 修复：应用主题时同步设置窗口的系统标题栏颜色、标题文字颜色和边框颜色，使其与面板一致；深色/浅色/跟随系统切换以及 DWM 合成/显示变化后都会重新对齐。
- 该修复对设置页和输入框等带系统标题栏的窗口同样有效。

验证：回归检查新增“面板与设置页界面配色一致”“两窗口 DWM 深色状态一致”，覆盖深色/浅色/跟随系统来回切换。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
可在设置中检查更新并选择“更新并重启”，配置与收纳数据保留。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
