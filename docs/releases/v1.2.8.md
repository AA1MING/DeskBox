# DeskBox 1.2.8

- 修复面板外圈偶发出现黑色虚线焦点框的问题。点击搜索框以外的区域时，焦点会从搜索框移交给面板根元素，WPF 会为这个可聚焦的根元素套用默认焦点视觉（一圈黑色虚线矩形），在面板边缘看起来像渲染故障。现已在根元素上禁用焦点视觉样式。

验证：回归检查新增“面板根元素不产生虚线焦点装饰”断言，覆盖焦点移交路径。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
可在设置中检查更新并选择“更新并重启”，配置与收纳数据保留。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
