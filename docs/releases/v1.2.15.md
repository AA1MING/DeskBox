# DeskBox 1.2.15

本次更新用 Apple 风格的「玻璃」替代原来的「云母」。

- 新增默认材质「玻璃」：对窗口背后的内容做实时模糊（合成器模糊 + 冷调中性灰、适中不透明度），呈现 Apple 风格的半透明玻璃质感。
- 玻璃不依赖 DWM 的云母系统材质，因此在之前出现“云母失效”的机器上也能正常显示。
- 背景材质选项调整为「玻璃 / 亚克力 / 纯色」；旧配置选择云母会平滑迁移为玻璃。
- 亚克力保留（仍是 DWM 系统材质）；关闭系统“透明效果”或启用高对比度时统一降级为纯色。
- 材质日志新增“系统背景 / 合成器”读回值，便于定位材质是否真正生效。

验证：回归检查更新为「玻璃走合成器模糊」并覆盖材质来回切换后仍生效；DWM 丢弃材质的恢复逻辑继续保留。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
可在设置中检查更新并选择“更新并重启”，配置与收纳数据保留。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
