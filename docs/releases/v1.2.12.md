# DeskBox 1.2.12

本次更新调整设置窗口的打开方式。

- 在面板里点“设置”现在只弹出设置窗口，主面板保持打开，不再先收起面板——符合“设置只是弹窗”的预期。
- 设置窗口作为主面板的子窗口显示在其上方，不会被置顶的面板挡住。
- 设置打开期间主面板暂停自动收起，关闭设置后恢复原有行为。

验证：回归检查新增“设置打开时冻结外部点击收起”“设置打开期间面板保持可见”断言。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
可在设置中检查更新并选择“更新并重启”，配置与收纳数据保留。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
