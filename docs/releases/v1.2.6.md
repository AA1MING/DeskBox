# DeskBox 1.2.6

- 主界面与设置页滚动条自动隐藏：停止滚动约 600 ms 后开始淡出，淡出约 180 ms。
- 再次滚动或将鼠标移到滚动条区域时显示，悬停与拖动期间持续可见。
- 隐藏不改变页面宽度，文字与图标不会跳动。

验证：139 项回归检查与 15 项单文件打包自检通过，覆盖滚动条静默隐藏、滚动显示、悬停、鼠标捕获和布局稳定性。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
可在设置中检查更新并选择“更新并重启”，配置与收纳数据保留。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
