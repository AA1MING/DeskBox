# DeskBox 1.2.13

本次更新修复窗口云母/亚克力材质偶发失效的问题。

- 根因：在远程桌面、切换桌面/GPU、开关系统“透明效果”等情况下，DWM 会静默丢弃窗口的云母/亚克力材质；而程序此前只按“缓存键”判断是否已应用，键没变就直接返回，于是材质丢失后再也不会重新应用，看起来就是主题失效。
- 修复：应用前会读取窗口真实的后台类型进行核对；一旦发现材质被丢弃（或收到 DWM 合成变化事件），立即重新应用，无需重启程序。
- 同时监听 DWM 合成状态与 DPI/显示变化，远程桌面接入/断开、切换显示器后材质会自动恢复。
- 右键菜单、设置等弹层同样受益，材质丢失后会恢复。

验证：回归检查新增“DWM 丢弃云母后重新应用主题可恢复”断言。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
可在设置中检查更新并选择“更新并重启”，配置与收纳数据保留。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
