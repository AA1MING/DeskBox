# DeskBox 1.2.16

本次更新让「玻璃」真正透出桌面。

- 上一版玻璃用的是合成器模糊叠加了较重的深色着色，结果看起来近乎不透明。现在玻璃改用系统“透明窗口”材质（DWMSBT_TRANSIENTWINDOW，即亚克力），会实时透出并模糊桌面内容，观感通透。
- 「亚克力」保留为合成器模糊 + 较重着色，质感更磨砂，和玻璃形成区分。
- 关闭系统“透明效果”或启用高对比度时仍统一降级为纯色。

验证：回归检查断言“玻璃使用系统透明窗口材质以透出桌面”，并覆盖材质来回切换后仍生效。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
可在设置中检查更新并选择“更新并重启”，配置与收纳数据保留。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
