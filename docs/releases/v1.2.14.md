# DeskBox 1.2.14

本次更新继续加固云母/亚克力材质，并增强排查信息。

- 面板在真正显示（取消 cloak、置顶）之后再按 DWM 实际状态补应用一次材质，降低显示瞬间材质被吞掉的概率。
- 背景材质日志现在记录了 DWM“读回”的真实材质类型，以及透明效果与深浅色状态。个别机器上如果云母仍不生效，可直接查看 `%AppData%\DeskBox\deskbox.log` 的“背景材质”行：
  - 读回=2 表示云母已生效；读回=1 表示被系统降级为纯色。
  - 透明=False 表示 Windows“透明效果”被关闭（设置 → 个性化 → 颜色），此时只能显示纯色。

验证：回归检查继续覆盖“DWM 丢弃云母后重新应用可恢复”。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
可在设置中检查更新并选择“更新并重启”，配置与收纳数据保留。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
