# DeskBox 1.2.0

- 新增 GitHub 更新：启动时后台检查最新正式版，发现新版后通过托盘提示，可在设置中关闭自动检查。
- 在设置或托盘进入更新，点击“更新并重启”即可下载、校验并自动替换；替换前等待收纳完成并保存配置。
- 更新保留程序路径、配置与收纳数据；新版启动失败时自动恢复旧版。
- 移除“按类型分组”，保留手动、名称与使用频率排序；旧配置自动切换为手动排序，保留现有顺序。
- 调整设置窗口高度，适应 Windows 显示缩放，更新按钮可通过滚动访问。

验证：101 项回归检查、17 项替换与回滚检查、15 项打包自检通过；完成实际 GitHub 下载校验及更新、排序菜单交互验证。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
从 v1.1.1 及更早版本升级：先退出旧版，再运行下载的新程序，配置与收纳数据保留。后续可使用程序内更新。
自动替换需要程序目录可写。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
