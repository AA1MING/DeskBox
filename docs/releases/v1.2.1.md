# DeskBox 1.2.1

- 修复设置窗口左上角显示默认图标的问题，统一窗口与对话框的 DeskBox 图标。
- 滚动条使用透明轨道与细圆角滑块，融入云母、亚克力和纯色背景；支持深浅主题，悬停和拖动时增强可见度。
- 去掉主界面和设置按钮的虚线焦点框，保留键盘操作。

验证：108 项回归检查与 15 项单文件打包自检通过，已核对深浅主题截图以及滚动条翻页、拖动和键盘聚焦。

Windows 10 1809+ / Windows 11，需 .NET 8 Desktop Runtime（x64）。
v1.2.0 用户可在设置中点击“检查更新”，再选择“更新并重启”；配置与收纳数据保留。

附件提供单文件程序、ZIP 压缩包、SHA-256 校验文件和第三方许可说明。
